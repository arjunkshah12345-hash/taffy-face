Pull my
face.

Grab any part of the face and stretch it like taffy. Let go and it snaps back. Please don't pull too hard. It hurts.

An open-source remake of @rameerez's site effect. One file, no dependencies. Your photo never leaves your browser.

Tip: use a photo with the background removed. On a Mac or iPhone, right-click or long-press a photo, choose Copy Subject, then paste it here (⌘V). The "ouch" photo is optional: a second photo with the same framing, shown while you pull.

<canvas id="face" style="width:500px;height:600px"></canvas>
<script type="module">
  import { createTaffy } from "https://cdn.jsdelivr.net/gh/arjunkshah12345-hash/taffy-face/taffy.js";
  createTaffy(document.getElementById("face"), {
    src: "me.png",          // transparent PNG works best
    grabSrc: "me-ouch.png", // optional
  });
</script>

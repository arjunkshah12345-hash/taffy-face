An open-source stretchy-face effect, remade from @rameerez's site. One file, no dependencies, MIT. Swap in your own photo below. It never leaves your browser.

Tip: on a Mac or iPhone, right-click or long-press a photo, choose Copy Subject, then paste it here (⌘V). You can also drag and drop an image.

Use it on your site

One import.
Any face.

Drop a canvas on the page, point createTaffy at a cut-out photo, and you're done. No build step, no framework.

Or copy taffy.js into your project and import it locally. It's about 300 lines.

<canvas id="face" style="width:500px;height:600px"></canvas>
<script type="module">
  import { createTaffy } from "https://cdn.jsdelivr.net/gh/arjunkshah12345-hash/taffy-face/taffy.js";

  createTaffy(document.getElementById("face"), {
    src: "me.png",          // transparent PNG works best
    grabSrc: "me-ouch.png", // optional: shown while pulling
  });
</script>
1

Cut out the photo

Use Copy Subject on a Mac or iPhone, or any background remover, and save a PNG. A photo with its background works too. The whole rectangle just becomes stretchy.

2

Add an "ouch" face

Optional. Take a second shot from the same spot pulling a silly face. It swaps in once someone pulls hard enough.

3

Let people pull

Mouse and touch both work. Listen for grab, ouch, release and calm events to add sounds or confetti.

Options

Tune the jiggle.

Every option is optional except src. Change them live with face.set({ ... }).

const face = createTaffy(canvas, opts);
await face.ready;
face.setImage(fileOrUrl);         // rest image
face.setImage(fileOrUrl, "grab"); // ouch image
face.on("ouch", () => {});
face.set({ damping: 4 });       // more wobble
face.destroy();

How it works

A mesh, a spring,
and a Gaussian.

The photo is drawn on a 56×56 grid of triangles with WebGL2. When you grab a point, every vertex gets a weight that falls off smoothly with distance, so the skin under your cursor moves most and the rest barely moves.

While you drag, each vertex chases pull × weight, passed through a tanh rubber band so it never tears. When you let go, an underdamped spring pulls it home, overshooting a little, which makes it jiggle.

Vertices with more weight are drawn in front, so the stretched part slides over the rest of the face instead of under it. Only opaque pixels can be grabbed, so the background stays put.
